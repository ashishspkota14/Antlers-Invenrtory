# Antlers Inventory

A single-purpose iPhone and Android app for Antlers Rooftop Tavern: count **Bar** and **Floor** stock, see what we have vs. what we need, and tick items off as they're ordered.

- **Owners** (two fixed emails): everything, plus invite people and set roles
- **Managers**: change Have / Need, finish counts, tick orders
- **Users**: view only

Stack: Expo SDK 58 (Expo Router, TypeScript) + Supabase (Postgres, Auth, Edge Functions).

```
src/app/              screens (Expo Router)
  sign-in.tsx         invite-only sign-in with an email code
  (app)/index.tsx     Bar tab
  (app)/floor.tsx     Floor tab
  (app)/orders.tsx    to-order list + ordered this week
  (app)/settings.tsx  profile, invite people, team roles
src/components/       InventoryList, NumberPad
supabase/migrations/  tables, roles, security rules, triggers
supabase/seed.sql     the 144 starting items (generated by scripts/make_seed.py)
supabase/functions/   invite-user (owner only)
supabase/templates/   invite + sign-in code emails
```

## Setup — Aashish (developer + owner 1)

Do these once, in order.

### 1. Supabase project
1. Go to supabase.com → **New project**. Name: `antlers-inventory`. Region: **West US**. Free plan is fine. Save the database password somewhere safe.
2. **Authentication → Sign In / Providers → Email**: keep Email on, turn **Allow new users to sign up** **off**.
3. **Authentication → Emails → Templates**:
   - **Magic Link**: subject `Your Antlers Inventory sign-in code`, body = contents of `supabase/templates/magic_link.html`
   - **Invite user**: subject `You're invited to Antlers Inventory`, body = contents of `supabase/templates/invite.html`
4. **Project Settings → API**: copy the **Project URL** and the **publishable (anon) key**.

> Supabase's built-in email sender only allows a few emails per hour. Fine for testing; before going live add a free SMTP sender (e.g. Resend) under **Authentication → Emails → SMTP**.

### 2. Code on your computer
```bash
git clone https://github.com/ashishspkota14/Antlers-Invenrtory.git
cd Antlers-Invenrtory
npm install
cp .env.example .env      # paste the URL and key into .env
```

### 3. Create the database
```bash
npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF     # the id in your project URL
npx supabase db push --include-seed                  # tables + rules + 144 items
npx supabase functions deploy invite-user
```

### 4. Add the two owners
In Supabase → **SQL Editor**, run (with the real emails):
```sql
insert into public.owner_emails (email) values
  ('aashish@example.com'),
  ('friend@example.com');
```
Then **Authentication → Users → Add user → Create new user** for each of the two emails (tick **Auto confirm**; the password doesn't matter, sign-in uses an email code). Both accounts become **Owner** automatically.

### 5. Run it
```bash
npx expo start
```
Scan the QR code with **Expo Go** on your phone (same Wi-Fi as your computer). Sign in with your email → enter the 6-digit code. Settings should say **Owner**.
